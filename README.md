# Bank Management System

A console-based Bank Management System developed using Core Java, JDBC, and MySQL.

## Technologies Used
- Core Java
- Object-Oriented Programming (OOP)
- JDBC
- MySQL
- Maven

## Features
- Create a bank account
- PIN authentication
- Secure PIN hashing
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Input validation
- Exception handling
- Database transaction management

## Database Setup
1. Open MySQL Workbench.
2. Create a database named `bank_management`.
3. Create the required `accounts` and `transactions` tables.
4. Configure the database connection in `DBConnection.java`.

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL connection.
4. Allow Maven to download the required dependencies.
5. Run `Main.java`.
6. Follow the console menu.

- Used SQL queries and PreparedStatement.
- Practised exception handling and transaction management.
